# MSMC Logo 生成 Prompt

## 正式版 v8（最终选定）

```
MSMC 产品 Logo 设计: 萌系二次元少女上半身头像，身体微侧 3/4 角度（不要完全正面）。长发及腰三态渐变配色：发根清透水蓝色 (#5DC8E8) → 中段日落暖琥珀色 (#e8964a) → 发梢深红色 (#c0392b)。配饰: 银色金属圆框眼镜 + 大尺寸黑色头戴式监听耳机（耳机线自然垂在肩膀旁边不要藏在头发里）。服装: 黑色高领毛衣。表情: 闭唇微笑（嘴角自然上扬，不要张嘴），面部五官线条必须清晰可见——鼻子要有自然的立体感和轮廓线，嘴巴唇线明确，刘海自然蓬松但不要盖眼睛或嘴巴。眼睛颜色: 冰蓝色（跟水蓝主色 #5DC8E8 呼应）。纯白干净背景方便后续抠图。构图: 头部到肩膀上半身特写，画面简洁聚焦角色。高质量精细萌系插画风格，柔和线条，pixiv 热门作品级别。
```

## 负面提示词

```
耳机线藏在头发里, 张嘴笑, 刘海盖眼睛, 面部模糊, 鼻子看不见, 嘴巴线条模糊, 不是微侧角度, 渐变不自然, 颜色不准
```

## 迭代历史

| 版本 | 关键变化 | 结果 |
|------|---------|------|
| v1 | 首次生成，渐变+耳机+眼镜+严肃表情 | 废稿（表情太硬，耳机线问题） |
| v2 | 温柔萌系 base | 废稿（渐变更规整但没微笑） |
| v3 | 微笑+高领毛衣 | 废稿（耳机线藏头发） |
| v4 | 微笑+高领+极光乱毛 | 废稿（乱毛太乱） |
| v5 | 重画面部清晰度 | 废稿（线条仍不够明确） |
| v6/v7 | 英文 prompt 触发敏感检测 | ❌ 生成失败 |
| **v8** | 微侧 45°+ 闭唇微笑+冰蓝眼+清晰线条 | ✅ **正式选定** |
| v9 | 微侧朝左+琥珀眼 | 废稿（朝左不如朝右） |

## 技术规格

- 原始尺寸: 1920×1920 JPG
- 裁剪后: 1880×1880 PNG（裁掉 2.5% 白色边框）
- ICO: 7 帧 32bpp (16/24/32/48/64/128/256)
- StartupLogo 显示: 200×200 object-fit:contain + 6s 呼吸动效

## 角色设定

- 身份: MSMC 品牌吉祥物（原创角色，不绑定 MC 世界观）
- 性格: 冷静可靠的服务器管理员，微笑传达"一切正常"
- 配色: 头发三态渐变 = MSMC 启动页配色系统（正常水蓝 → 警告日落黄 → 故障血红）
- 配饰语义: 耳机 = 监控服务器日志 / 眼镜 = 仔细排查问题 / 高领 = 专业稳重
