# 系统监控页面大改实现计划

## 一、需求总结

1. **CPU/内存折线图合并**：从左右两栏的两个独立图表，改为"超级拼装"——一张图里同时显示 CPU 和内存两条曲线，不同颜色区分
2. **X轴时间标签**：折线图下方显示时间段（开始时间 - 结束时间，以及关键时间点刻度）
3. **CPU物理拓扑可折叠**：CPU 物理拓扑栏目支持展开/折叠，默认展开，折叠时只保留标题栏
4. **上方仪表盘不动**：4 列仪表盘（CPU/内存/磁盘/线程）保持原样

## 二、现状分析

### 2.1 当前结构

```
系统监控页面
├── 标题 + 开始/停止按钮
├── 4列仪表盘（CPU / 内存 / 磁盘 / 线程） ← 不动
├── CPU 物理拓扑卡片 ← 加折叠
├── 历史范围选择器（今天/3天/7天/30天）
└── 2列折线图（CPU左 / 内存右） ← 合并为一张图
```

### 2.2 现有组件

- **SimpleLineChart**：单数据系列 SVG 折线图，支持间隙断开、面积填充、Tooltip
- **CpuTopology**：CPU 物理拓扑卡片，展示每核使用率
- **数据**：`history: HistoryPoint[]`，每个点含 `timestamp / cpuUsagePercent / memoryUsagePercent`

## 三、设计方案

### 3.1 合并折线图（DualLineChart）

**一张图，两条线**：
- CPU 线：绿色（`var(--md-gauge-green)`），实色面积填充（低透明度）
- 内存线：蓝色（`var(--md-primary-500)`），实色面积填充（低透明度）
- 两条线共用 Y 轴（0-100%）和 X 轴（时间）
- 悬停时 Tooltip 同时显示 CPU 和内存两个数值
- 图例在标题区：● CPU 使用率（绿）  ● 内存使用率（蓝）

**X 轴时间刻度**：
- 底部显示 3~5 个时间刻度点（根据数据跨度动态选取）
- 格式：`HH:mm`（当天）或 `MM-dd HH:mm`（跨天）
- 最左侧显示开始时间，最右侧显示结束时间

**组件名**：`DualLineChart`（双数据系列折线图）

### 3.2 CPU 拓扑折叠

**交互**：
- 标题栏右侧加一个折叠箭头图标（▶ / ▼）
- 点击标题栏任意位置切换展开/折叠状态
- 折叠时：卡片高度收缩到仅标题栏高度，内容区域 `max-height: 0` + `overflow: hidden` + 过渡动画
- 展开时：平滑展开内容
- 状态用 `useState` 管理，默认展开

**折叠标题栏显示信息**：
- 左侧：🖥️ CPU 物理拓扑
- 中间（折叠时新增）：N 物理核 / M 逻辑核 概要信息
- 右侧：折叠箭头 ▲ / ▼

### 3.3 调整后的页面布局

```
系统监控页面
├── 标题 + 开始/停止按钮
├── 4列仪表盘（不动）
├── 历史范围选择器（移到折线图上方，更合理）
├── 合并折线图（CPU + 内存 同图，底部时间轴）
└── CPU 物理拓扑（可折叠）
```

> 把历史范围选择器移到折线图上方更合理，因为范围选择直接影响折线图显示。

## 五、实现步骤

### Step 1：新建 DualLineChart 组件

**功能**：
- 同时渲染 CPU 和内存两条折线 + 面积填充
- 共用 Y 轴（0-25-50-75-100）
- X 轴时间刻度（3-5 个刻度点）
- 悬停 Tooltip 同时显示两个数值
- 图例（两条线的颜色和名称）
- 支持间隙断开（gapThresholdSec）
- 支持时间段显示（开始时间 - 结束时间）

**Props**：
```ts
interface DualLineChartProps {
  data: HistoryPoint[]          // 历史数据点
  height?: number               // 图表高度
  label?: string                // 标题
  gapThresholdSec?: number      // 间隙阈值
  cpuColor?: string             // CPU 线颜色
  memoryColor?: string          // 内存线颜色
}
```

**关键实现细节**：
1. 两条线分别计算 pathD 和面积段（同 SimpleLineChart 逻辑 × 2）
2. X 轴刻度：根据数据跨度计算均匀分布的 3~5 个时间点
3. Tooltip：悬停时找最近的数据点索引，同时显示 CPU 和内存值
4. 图例：标题栏右侧显示两个彩色圆点 + 文字

### Step 2：CPU 拓扑加折叠功能

在 `CpuTopology` 组件内部：
1. 新增 `useState<boolean>('collapsed', false)` 或从 props 接收
2. 标题栏加点击事件 + 右侧箭头图标
3. 内容区域用 `max-height` + `overflow: hidden` + `transition` 实现平滑展开折叠
4. 折叠状态下箭头朝右（▶），展开状态朝下（▼）
5. 整个标题栏可点击（手型光标）

> 折叠状态放在组件内部自管理，不需要提升到父组件。

### Step 3：调整页面布局

1. 把折线图区域从 2 列改为 1 列，使用 `DualLineChart`
2. 历史范围选择器移到折线图上方（更合理的信息层级）
3. CPU 拓扑移到折线图下方
4. 移除旧的 `cpuChartData` / `memChartData` 单数据转换
5. 移除 `SimpleLineChart` 在本页的使用（组件本身保留，其他页面可能用）

### Step 4：样式细节打磨

- 两条线的面积填充透明度区分开（CPU 略深，内存略浅，避免重叠时看不清）
- Tooltip 用两行布局，分别带颜色前缀圆点
- X 轴刻度文字：11px，浅色，居中对齐
- 折叠动画时长 0.25s，ease 曲线
- 折叠后卡片底部间距保留（不空落落的）
