# 服务器核心配置文件全面中文翻译计划

## 摘要

为 MSMC（McServerGuard）项目收录的全部 35 种 Minecraft 服务器核心，联网调研其所有原生配置文件，逐一翻译为自然中文（让小白也能看懂熟用），产出双轨成果物：
1. **Markdown 参考文档**：每种核心一份独立完整的配置文件中文手册
2. **代码集成**：将所有翻译写入 `ConfigDescriptorRegistry.cs`，让配置编辑器实时显示中文翻译和校验规则

## 翻译规范

### 翻译表格格式（Markdown 文档）
每种核心的文档中，每个配置文件使用如下表格格式：

```markdown
### server.properties（服务器属性）

| 配置项（英文） | 中文翻译 | 默认值 | 值类型 | 取值范围 | 需重启 | 说明 |
|---|---|---|---|---|---|---|
| server-port | 服务器端口 | 25565 | 数值 | 1-65535 | 是 | 玩家连接服务器时使用的端口号 |
| online-mode | 正版验证 | true | 布尔 | true/false | 是 | 是否要求玩家使用 Minecraft 正版账号登录 |
| gamemode | 游戏模式 | survival | 枚举 | survival/creative/adventure/spectator | 是 | 新玩家加入服务器时的默认游戏模式 |
```

### 翻译原则
1. **小白友好**：翻译要让从未开过服的人也能看懂。例如 `view-distance` 不译为"视图距离"而译为"视野距离（区块数）"
2. **枚举值也翻译**：如 `gamemode` 的值 `survival` → `生存`、`creative` → `创造`，在说明列标注
3. **键名不翻译**：保持英文键名不变（代码需要），只翻译显示名和说明
4. **值类型标注**：数值/布尔/枚举/字符串/列表/路径
5. **取值范围明确**：数值标 min-max，枚举列出所有可选值并翻译
6. **重启标注**：修改后是否需要重启服务器才生效

### 代码集成格式（ConfigDescriptorRegistry.cs）
```csharp

{
    var file = "purpur.yml";

    Register(new ServerConfigDescriptor
    {
        Key = "settings.use-alternate-keepalive",

        Category = "网络",
        DefaultValue = "false",
        AllowedValues = ["true", "false"],
        ValueType = "bool",
        RequiresRestart = true
    });

    // ... 更多条目
}
```

## 假设与决策

1. **TOML 格式处理**：Velocity 的 `velocity.toml` 和 Forge 的 `forge-server.toml` 当前被 ConfigFormatDetector 标记为 Unknown。需要先在 ConfigFormatDetector 中添加 TOML 格式支持（或依赖现有的回退机制），再注册描述符。
2. **HOCON 格式处理**：Sponge 的 `global.conf` 使用 HOCON 格式。同样需要检测是否被现有解析器支持，可能需要添加 HOCON 解析或依赖回退。
3. **.conf 格式处理**：Magma 的 `magma.conf` 实际是 Properties 格式，应被现有解析器覆盖。
4. **Nukkit 基岩版 server.properties**：基岩版的 server.properties 与 Java 版字段不同（如 `server-port` 用 UDP、`motd` 格式不同），需要单独注册一套描述符，但当前注册表用文件名做 key 会导致冲突。决策：用核心类型前缀区分，如 `nukkit-server.properties`。
5. **文档语言**：全部使用简体中文。
6. **停更核心标注**：文档开头标注「⚠️ 此核心已停止维护/归档」，但翻译仍然完整提供。
